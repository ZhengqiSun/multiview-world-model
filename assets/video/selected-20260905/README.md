## 06 · 从不可见到可见：三视角

[播放 / 下载成片](06-player-reveal-three-views.mp4)

### 选片原文

> 组名：3视角（从视野中无人到可见其他玩家身体和动作，排除首帧泄露的可能性，体现模型对于多玩家位置姿态的多视角一致性问题的解决效力）（与lingbot-world-base 只微调推理结果做对比体现稠密特征图对于玩家位置和动作的信息存储与利用）

> 作用：还需要再直接用lingbot-world-base直接推理这些片段，先找找服务器上有没有
