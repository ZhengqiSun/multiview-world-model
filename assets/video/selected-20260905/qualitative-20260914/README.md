A/B/C沿用当前选图页的0、1、2、3、4、5秒版；0秒统一为GT输入参考，不算生成效果。每图分为两个时间块。人物框在同视角、同时刻的不同方法间固定，缺人时保留空框；人物完全离开视野时不猜测其位置。局部或重叠身体可共用区域框，不将框数等同人数。框不随生成结果重新检测或调整，不证明生成身份一致。

B视频包含完整81帧、16fps、三方法×双视角。橙色框依据同一记录目标、实际逐帧相机与内参计算，与图B已核查采样点的框完全相同；投影区域再经GT逐帧审看。框是参考区域，不是像素级分割。原帧显示保持比例，不插帧、不改变速度；视频为H.264显示副本，不声称逐像素无损。

H属于历史版本，GT与生成源的原生高度不同，显示保持比例；不与其余图合称一个统一模型结果。所有图都来自事后选片，保留失败，不据单图宣称全测试集平均优势或完整训练谱系未见。本批没有新推理，也没有发布权重、运行脚本或内部路径。原04–07素材保留。
